────────────────────────────────────────────────────────────────
第 1 章  范围
────────────────────────────────────────────────────────────────

1.1 目的

本协议定义 formant_synth 从标准 MIDI 生成共振峰歌声 SMF
的完整技术规范。实现者应依据本协议产出可互通的文件。

1.2 定位

输入 MIDI 是参数源与 meta 源；输出是从零生成的全新 SMF。
两者不是同一文件，输出不基于输入轨编辑。

1.3 不涵盖

  - 音源内部的波形生成
  - 具体 SoundFont 的音色映射
  - 歌词语言学分析（分词、注音）
  - DAW 音序器架构（见独立协议）


────────────────────────────────────────────────────────────────
第 2 章  术语
────────────────────────────────────────────────────────────────

  PPQN              每四分音符的 tick 数
  音素              一个可映射到共振峰数据的发音单元
  韵母              中文音素，共 38 项
  元音              日文（6）/ 英文（12）音素
  共振峰            声道共振频率 F1/F2/F3…
  动程              一个音素内部的共振峰时间轨迹
  段                动程的一个时间片，段边界重触发 note
  继承              输入 meta 逐条搬到输出 Setup 轨
  重写              输出重新生成，不参考输入对应事件
  源力度            输入 SMF 中该音符的 note_on velocity，范围 1–127
  通道音量          每个输出通道的 CC7 固定值，0–127
  弯音范围          RPN 0 指定的半音数，整数，范围 1–24
                    默认：GS/XG=12，GM/无 SysEx/unknown=2
  弯音范围时间线    每通道一条有序 (tick, semitones) 事件序列
  表情时间线        所选输入通道的 CC11 事件序列，默认 127
  onset 脉冲        音节开头噪声声母触发的 1 tick 噪声脉冲
  coda 脉冲         音节结尾噪声韵尾触发的噪声脉冲
  泛音通道          H2/H3/H4，频率严格等于 2/3/4 × F0_freq

第 3 章  系统架构
────────────────────────────────────────────────────────────────

3.1 数据流

  输入 SMF（只读）
    │
    ├─ 探测：sysex → input_format
    │
    ├─ 读取：
    │    note_on/off    → Note 列表（含源 velocity）
    │    lyrics         → LyricEvent 列表
    │    set_tempo      → TempoEvent 列表
    │    time_signature → TimeSignatureEvent 列表
    │    pitch_wheel    → 参考（不直接透传）
    │    RPN 0          → 每通道 PitchBendRangeTimeline
    │    CC11           → 表情时间线
    │    key_signature  → KeySignatureEvent 列表（继承）
    │
    ├─ 处理：
    │    shrink_overlaps          重叠 gate 收缩
    │    sanitize_lyrics          LRC 清洗
    │    split_syllables          音节切分
    │    filter_known_phonemes    白名单过滤
    │    align_syllables_to_notes 邻近匹配
    │    formant_trajectory       动程展开
    │
    ├─ 合成：16 通道 × 每音素 → 事件流
    │
    └─ 输出 SMF（全新，Type-1，17 轨）

3.2 处理层

  输入层    解析 MIDI，收集参数           read_midi
  清洗层    LRC 剥离、音节切分、音素过滤  sanitize_lyrics /
                                          split_syllables /
                                          filter_known_phonemes
  识别层    音节 → 共振峰                _zh_formant /
                                          _ja_formant /
                                          _en_formant /
                                          nearest_phoneme
  对齐层    音节 → 音符                  align_syllables_to_notes
  合成层    音符 → 16 通道事件           note_to_events
  组装层    事件 → 轨                    build_16ch_tracks
  输出层    写文件                       convert


────────────────────────────────────────────────────────────────
第 4 章  输入规格
────────────────────────────────────────────────────────────────

4.1 文件要求

  格式      标准 MIDI File（SMF）
  类型      0 或 1
  PPQN      ≥ 96（低于此值终止）
  通道      1–16；通道 10 不可用（鼓）

4.2 音符读取

  - 只读取选定通道的 note_on / note_off
  - note_on velocity = 0 视为 note_off
  - 重叠音符按「后到先收缩前一个」规则处理
  - 零长度音符丢弃
  - 轨末挂音强制闭合
  - 保留每个音符的源 velocity

4.3 Meta 读取（继承）

  set_tempo          全部保留，按 tick 排序去重，同 tick 保留最后一条
  time_signature     全部保留，按 tick 排序去重，同 tick 保留最后一条
  key_signature      全部保留（若存在）
  smpte_offset       全部保留（若存在）
  text/copyright     丢弃
  marker/cue         丢弃
  track_name         丢弃，输出重写
  end_of_track       丢弃，输出重写
  CC7                不读取输入，输出按 7.3 表值重写
  CC11               读取所选输入通道，输出广播到全部 Voice 轨
  其他 CC            不读取、不透传

4.4 歌词读取

  来源：所选通道所在 track 的 lyrics 元事件。

  清洗规则（按顺序）：
    1. LRC 时间戳： [mm:ss.xx] <mm:ss.xx> [mm:ss:xx]
    2. LRC 元数据： [ar:] [ti:] [al:] [by:] [offset:]
                    [re:] [ve:] [length:] [au:] [tool:] [encoding:]
    3. 残留方括号块： [chorus] [间奏]
    4. 行注释：       // # ; 到行尾
    5. 控制字符 / 换行 / 制表 → 空格
    6. 多空格折叠
  清洗后空串不入列。

4.5 编码

  - 从 mido 的 Latin-1 壳剥出原始字节
  - encoding='auto' 时按语言尝试：
      zh：utf-8 → gb18030 → shift_jis
      ja：utf-8 → shift_jis → gb18030
      en：utf-8 → gb18030 → shift_jis
  - 全部失败落 latin-1
  - 可显式指定 --encoding

4.6 RPN 0 读取

  - 严格状态机：CC101 → CC100 → CC6 → (CC38)
  - 仅当 RPN 选择为 [0, 0] 时记录 CC6 值
  - 每次生效记录一条 PitchBendRangeEvent(tick, channel, semitones)
  - 每通道独立维护一条时间线
  - 同一 tick、同一通道多次生效：后写覆盖前写
  - CC38 为 LSB，本协议忽略
  - 半音数范围：整数 1–24，超界取 clamp(1, 24)

4.6.1 弯音范围时间线解析

  输入只读取所选输入通道的 RPN 0。
  输出 16 个 Voice 通道轨共用同一条时间线（广播）。

  初始值 initial_R：
    - 若输入 RPN 0 在 tick 0 有事件，取该事件值
    - 否则按格式默认：GS/XG=12，GM/unknown=2

  查询函数 R(tick, channel) =
    tick 之前（含 tick）最近一条事件的值，若无 → initial_R

  时间线补全：
    - 首条事件 tick > 0，则在 tick 0 补写 initial_R
    - 时间线为空，写一条 tick 0 的 initial_R

4.7 CC11 读取

  - 只读取所选输入通道的 CC11
  - 建立表情时间线，默认 127
  - 同一 tick 多次生效：后写覆盖前写
  - 若输入无 CC11，时间线仅含 tick 0 的默认值 127

4.8 格式探测

  扫全部轨的 sysex，按签名识别：
    GS      41 10 42 12
    XG      43 10 4C
    GM      7E 7F 09 01
    GM2     7E 7F 09 03
    unknown 均不匹配
  探测结果仅用于日志与默认值推断，不决定输出。

5.4 最近音素替换

  1. _vowel_hint 从字符串抽取近似共振峰
  2. 遍历该语言全部 key，计算：
       fd = sqrt((f1-f1')² + (f2-f2')² + (f3-f3')²) / 3000
       sd = 1 - SequenceMatcher(s, key).ratio()
       score = 0.55 × fd + 0.45 × sd
  3. 取 score 最小者
  4. 若 score > 0.85 → 放弃，落中性 (500, 1500, 2500)

5.5 最近邻候选排除
  i_apical_back / i_apical_front 不参与最近邻候选。

第 6 章  处理管线
────────────────────────────────────────────────────────────────

6.1 重叠收缩
  a_end = a.start + a.dur
  if a_end > b.start:
      a.dur = max(0, b.start - 1 - a.start)
  结果可能产生零长度音符，在合成层丢弃。

6.2 音节摊平
  对每个 LyricEvent：
    span = next_tick - tick（末条用 tick + PPQN）
    n = 音节数
    第 j 个音节 tick = tick + span × j // n

6.3 邻近匹配
  d_prev = target - prev.tick
  d_next = next.tick - target
  if d_next ≤ d_prev: 取 next
  else: 取 prev
  相等时取后一个。

6.4 白名单过滤
  - is_known_phoneme(syl, lang) 返回 True 才保留
  - 空串、纯标点、非歌词字符被剔除

6.5 动程展开
  r = syllable_to_formant(syl, lang)
  if r is None:
      traj = [(0, 1, extend_formants(500, 1500, 2500))]
  else:
      pts = [extend_formants(F1, F2, F3)]
      if F1t is not None:
          pts.append(extend_formants(F1t, F2t, F3t))
      n = len(pts)
      traj = [(i/n, (i+1)/n, pts[i]) for i in range(n)]

  extend_formants 外推 F4–F8：
    F4 = F3 + 400
    F5 = F4 + 800
    F6 = F5 + 500
    F7 = F6 + 500
    F8 = F7 + 500

第 7 章  输出规格
────────────────────────────────────────────────────────────────

7.1 文件结构
  类型      Type-1
  PPQN      与输入一致
  轨数      17
  说明      轨 0 = Setup；轨 1–16 = 16 个通道轨（CH0–CH15）

7.2 轨分配
  轨    通道  角色
  0     —     Setup
  1     0     F0 基频（带滑音）
  2     1     F1
  3     2     F2
  4     3     F3
  5     4     F4
  6     5     F5
  7     6     F6
  8     7     F7
  9     8     F8
  10    9     噪声（GM 下禁用，合并到 CH8）
  11    10    H2 = 2×F0
  12    11    H3 = 3×F0
  13    12    H4 = 4×F0
  14    13    气声 = 1.005×F0
  15    14    F1W = F1 + 100
  16    15    F2W = F2 + 200

  GM 下 CH9 与 CH8 共用 MIDI 通道 9。
  CH8 的 RPN 0 / CC7 / CC11 / bend 同样作用于噪声事件。
  噪声脉冲不单独发送 bend，也不继承 F8 的 bend。
  泛音通道 H2/H3/H4 的频率必须严格等于 2/3/4 × F0_freq，
  各自独立走 7.6 公式。不允许使用固定 note 偏移。

7.3 通道音量（CC7）
  F0            100
  F1            100
  F2            90
  F3            80
  F4            70
  F5            60
  F6            55
  F7            50
  F8            45
  噪声          45
  H2            60
  H3            50
  H4            40
  气声          50
  F1W           55
  F2W           45

  - CC7 是通道级音量，写在每个 Voice 轨 tick 0
  - CC7 不随后续事件变化
  - CC7 不读取输入 CC7，也不透传
  - 全局缩放：--cc7-scale，默认 1.0
  - 输出 CC7 = clamp(round(表值 × scale), 0, 127)
  - 谐波频谱目标：锯齿波型，偶次略强于奇次

7.4 Setup 轨内容
  1. track_name = 'Setup'
  2. SysEx（按输出格式）
  3. 拍号兜底（若输入无 tick 0 拍号）
  4. time_signature 全部（按 tick）
  5. set_tempo 全部（按 tick）
  6. 渐慢曲线（若启用）
  7. key_signature 全部（按 tick，若输入有）
  8. end_of_track

  同 tick 合并排序键：(tick, kind)，
  kind=0 拍号/调号，kind=1 tempo。
  同 tick 多个 tempo/拍号时，保留最后一条。
  渐慢曲线 = 16 条 set_tempo 事件，按 tick 升序。

7.5 Voice 轨内容

  每个 Voice 轨在 tick 0 必须先写初始化事件，顺序固定：
    track_name = 'CHn'
    [按格式] 通道初始化（CC0 / CC32 / PC）
    RPN 0 = R(0, ch)     CC101=0, CC100=0, CC6=R, CC38=0
    CC7 = 7.3 表中该通道的值 × --cc7-scale
    CC11 = 初始表情值
  以上初始化事件全部位于 tick 0，且在 tick 0 的 note_on 之前。

  之后为事件流，按 (tick, priority) 排序：
    0  note_off
    1  RPN
    2  ctrl / pitch_wheel / CC11
    3  note_on

  同一 tick 上的顺序：
    note_off → RPN → ctrl → note_on
  段边界：先 note_off，再 pitch_wheel，再 note_on。

  RPN 事件：
    - 若时间线在 tick > 0 有事件，按 tick 写入
    - 每条 RPN 0 消息序列：CC101=0, CC100=0, CC6=R, CC38=0
    - 若某音符 tick 处 R 与前一事件相同，不重复写 RPN 0

  note_on velocity：
    来源：源 SMF 中该音符的 note_on velocity
    换算：clamp(round(源 velocity × velocity_scale), 1, 127)
    默认 velocity_scale = 1.0
    - 所有 16 个输出通道的同一音符，使用相同的 velocity_out
    - 通道之间的响度差异由 CC7 体现
    - 段边界重触发时，各段使用同一 velocity_out，不衰减
    - 噪声 onset / coda 使用其匹配音符的 velocity_out
    - 源 velocity = 0 已按 note_off 处理
    - 结果下限为 1

  CC7：
    - 输入 CC7 不读取、不透传
    - 输出 CC7 固定为 7.3 表值 × --cc7-scale
    - 写在每个 Voice 轨 tick 0，只写一次

  CC11：
    - 保留源 SMF 所选通道的 CC11 时间线
    - 输出广播到全部 16 个 Voice 通道
    - CC11 属于 ctrl 事件，优先级 2
    - CC11 不改变 velocity，也不改变 CC7
    - 由音源用 CC11 缩放当前通道的整体音量
    - 若输入无 CC11，时间线仅含 tick 0 的默认值 127

  note_off velocity = 64

7.6 频率 → note + bend

  在给定 tick、通道 ch 上，令 R = R(tick, ch)：
    note_exact = 69 + 12 × log2(freq / 440)
    note       = clamp(round(note_exact), 0, 127)
    note_freq  = 440 × 2^((note - 69) / 12)
    cents      = 1200 × log2(freq / note_freq)
    bend       = clamp(round(8192 + cents × 8192 / (R × 100)), 0, 16383)

  - R 为当前弯音范围，整数半音，有效范围 1–24
  - R × 100 为对应音分数
  - 8192 为 bend 中心，0 / 16383 为上下限
  - 若所需 bend 超界，clamp 到边界并记 warning

  泛音通道 H2/H3/H4：
    H2_freq(t) = 2 × F0_freq(t)
    H3_freq(t) = 3 × F0_freq(t)
    H4_freq(t) = 4 × F0_freq(t)
    每个频率独立走上述公式。
    不允许使用 F0 的 note 加 12 / 19 / 24 的固定偏移。
    F0 带 bend 时，H2/H3/H4 的 cents 各自独立计算。

7.7 滑音
  作用通道    CH01（F0）、CH11（H2）、CH12（H3）、CH13（H4）
  起始位置    音符时长 70% 处
  步数        16
  目标        --slide 半音数
  共振峰通道  CH02–CH09、CH14–CH16 不滑
  滑音只发 pitch_wheel，不重触发 note_on / note_off
  滑音期间 bend 使用当前通道当前 tick 的 R(t, ch)
  滑音期间 H2/H3/H4 必须同步重算
  若 --slide ≠ 0 且目标半音数超出 R，clamp 到边界并记 warning

7.8 渐慢
  位置         Setup 轨
  区间         最后一个音符的起点到终点
  步数         16
  参数         --rit-start / --rit-end
  渐慢曲线 = 16 条 set_tempo 事件，按 tick 升序

第 8 章  格式适配
────────────────────────────────────────────────────────────────

8.1 通道初始化
  GS:  CC0=8, CC32=0, PC=80, RPN 0 初始=12, CC11 初始=127
  XG:  CC0=0x40, CC32=0, PC=80, RPN 0 初始=12, CC11 初始=127
       不支持时退化为 CC0=0 + PC=80
  GM:  PC=80, RPN 0 初始=2, CC11 初始=127, GM 规范无正弦波
  unknown: PC=80, RPN 0 初始=2, CC11 初始=127

8.2 Setup 轨 SysEx
  GS:
    GS Reset:    F0 41 10 42 12 40 00 7F 00 41 F7
    CH10 解锁:   F0 41 10 42 12 40 10 15 00 1B F7
  XG:
    XG Reset:    F0 43 10 4C 00 00 7E 00 F7
    CH10 解锁:   F0 43 10 4C 08 1A 00 00 F7
  GM:
    无 SysEx，CH10 保持鼓通道，噪声合并到 CH8（MIDI 通道 9）

  Roland checksum 公式：
    checksum = (128 - ((addr0+addr1+addr2+data) & 0x7F)) & 0x7F
  GS CH10 解锁校验：
    地址 40 10 15，数据 00
    sum = 0x40 + 0x10 + 0x15 + 0x00 = 0x65
    checksum = (128 - 0x65) & 0x7F = 0x1B
  GS Reset 校验：
    地址 40 00 7F，数据 00
    sum = 0x40 + 0x00 + 0x7F + 0x00 = 0xBF
    checksum = (128 - 0xBF) & 0x7F = 0x41

8.3 格式转换
  输入格式与输出格式解耦：
    输入      --format    输出
    GS        gs          GS
    XG        gs          GS（转换）
    GM        gs          GS（转换）
    GS        xg          XG（转换）
    XG        xg          XG
    GM        xg          XG（转换）
    任意      gm          GM
    unknown   任意        按 --format

8.4 单通道 NRPN 方案（兼容旧音源）
  GS:
    NRPN 1,32 = freq_to_cc(F2, 600, 3000)
    NRPN 1,33 = 100 if F2 < 1500 else 80
  XG:
    CC74 = freq_to_cc(F2, 600, 3000)
    CC71 = 100 if F2 < 1500 else 80
  GM:
    NRPN 64,0 = F1（50–1000 Hz → 0–16383）
    NRPN 64,1 = F2（600–3000 Hz → 0–16383）
    NRPN 64,2 = F3（2000–3500 Hz → 0–16383）
    NRPN 64,3 = 8192
    NRPN 64,4 = 12000（onset 噪声）

第 10 章  错误处理
────────────────────────────────────────────────────────────────

10.1 终止条件
  PPQN < 96           输入 PPQN=X 低于最低要求 96
  通道不在 1–16       通道必须在 1-16 之间
  通道 = 10           通道 10 为 GS/GM 鼓通道，不能用于歌声
  无音符              MIDI 中未找到通道 N 的音符
  BPM ≤ 0             BPM 必须大于 0

10.2 容错
  零长度音符          丢弃
  轨末挂音            强制闭合
  无法识别音节        走最近音素替换
  最近音素 score>0.85 落中性 (500, 1500, 2500)
  歌词解码失败        落 latin-1
  输入无 tempo        补 500000（120 BPM）@ tick 0
  输入无 tick 0 拍号  补 4/4
  输入无 RPN 0        按格式默认：GS/XG=12，GM/unknown=2
  RPN 0 值超界        取 clamp(1, 24)
  输入无 CC11         默认 127
  输入无 CC7          输出按 7.3 表值重写
